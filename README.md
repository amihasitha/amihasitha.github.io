# Hasitha Anuruddha — Portfolio

Personal portfolio site for **Hasitha Anuruddha**, Senior Software Engineer specializing in Magento, Shopify, WordPress, and full-stack eCommerce development.

**🔗 Live site:** https://amihasitha.github.io

## About

A single-page portfolio built around an eCommerce/dev theme:

- **Receipt-style hero** — an "itemized receipt" summarizing years of experience, companies worked with, and tech stack
- **Git-log styled experience timeline** — each role shown like a commit entry with a version tag (e.g. `Jul 2024 — present`)
- **Skills** grouped by category (Backend & eCommerce, Dev & Database, Infrastructure & DevOps, General)
- **Selected projects** with links to live stores shipped (Lowe's, Waterbom, Wilcon, Kosé, MissyEmpire, and more)
- **Education & certification**

## Built With

- HTML5 & CSS3 (no build tools, no dependencies)
- [Google Fonts](https://fonts.google.com/) — Space Grotesk, Inter, IBM Plex Mono
- Hosted on [GitHub Pages](https://pages.github.com/)

## Running Locally

No build step required — just open the file in a browser:

```bash
git clone https://github.com/amihasitha/amihasitha.github.io.git
cd amihasitha.github.io
open index.html      # or double-click the file
```

## Deployment

This repo is already named `amihasitha.github.io`, so GitHub Pages serves it automatically from the `main` branch. Any change pushed to `main` goes live at https://amihasitha.github.io within a minute or two — no extra deployment step needed.

## Updating Content

All content (experience, skills, projects, contact info) lives directly in `index.html`. To update:

1. Edit the relevant section in `index.html`
2. Commit and push to `main`
3. Refresh the live site after a minute to see changes
